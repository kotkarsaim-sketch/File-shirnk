Real-World Application

ZIP • Huffman • LZ77
🗃️

ZIP / DEFLATE

Uses LZ77 + Huffman coding. Frequent byte patterns are replaced with shorter codes — exactly what File-Shrink simulates at the word level.

🌳

Huffman Coding

Assigns shorter bit sequences to more frequent symbols. The compression ratio you see is a simplified Huffman estimate for frequent words.

📚

Dictionary Compression

Custom compression dictionaries (like in Brotli) map frequent strings to tokens. File-Shrink builds exactly that dictionary from your file.
